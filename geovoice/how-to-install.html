INSTALLATION GUIDE

How to Install GeoVoiceRoom

Ikuti langkah-langkah mudah di bawah ini untuk memasang ekstensi ke browser Chrome Anda.

1
Langkah Pertama

Download Ekstensi

Unduh file paket ekstensi GeoVoiceRoom langsung melalui tombol di bawah ini ke perangkat Anda.

Download File .zip / .crx
2
Langkah Kedua

Buka Menu Ekstensi & Pasang

Buka tab baru di browser Chrome Anda, ketik chrome://extensions/ di URL bar.

  • Aktifkan Developer Mode di pojok kanan atas.
  • Drag & Drop file yang sudah di-download tadi ke halaman extensions.
  • Selesai! Ekstensi siap digunakan.
